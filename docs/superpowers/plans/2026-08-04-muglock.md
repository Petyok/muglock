# muglock Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. In this repo the plan is executed via the author's standard multi-agent workflow (plan-validate → parallel builders → sanity → integrate → validate → test → review); task numbers below are the builder ownership units.

**Goal:** macOS-style FaceID screen unlock for Hyprland: quickshell QML lockscreen with animated face-scan plaque, howdy recognition, chirp on success, password fallback.

**Architecture:** A quickshell config (`qs -c muglock`) hosts `WlSessionLock` with a per-screen surface (clock/date/password via `PamContext`, animated FaceID plaque). The QML itself spawns `sudo -n howdy compare <user>` through `Process` and drives animations off the exit code. hypridle triggers lock/wake through `qs ipc`. Mock + dev modes allow full development without root, camera, or locking the session.

**Tech Stack:** quickshell 0.3.0 (Qt6 QML), bash, ffmpeg (chirp), howdy (runtime dep), dpkg-deb (release artifact), PKGBUILD (AUR).

## Global Constraints

- All docs, code comments, and commit messages in English.
- README MUST carry the "100% vibecoded" badge + one line stating the code was written by Claude in dialogue. Author requirement; never remove.
- NEVER edit `/etc/pam.d/*`. The only privileged config is `/etc/sudoers.d/muglock`, always validated with `visudo -cf` before install.
- Camera scan hard-capped at 10 s (`FaceScanner.timeoutMs`), camera released after.
- Verified quickshell 0.3.0 API (from installed qmltypes — do NOT invent names; check `/usr/lib/qt6/qml/Quickshell/**/*.qmltypes` when unsure):
  - `Quickshell.Wayland`: `WlSessionLock { locked: bool; secure: bool (ro); default property surface }`, `WlSessionLockSurface`.
  - `Quickshell.Services.Pam`: `PamContext { config, configDirectory, user, active, message, responseRequired, responseVisible; function start(); function respond(r); function abort(); signal completed(result); PamResult.Success }`.
  - `Quickshell.Io`: `Process { command: list<string>, running, environment, signal exited(exitCode, exitStatus) }`, `IpcHandler { target: string; plain functions }`. CLI: `qs -c muglock ipc call <target> <fn>`.
- `MUGLOCK_MOCK=ok|fail|slow` swaps howdy for `scripts/howdy-stub.sh`; `MUGLOCK_DEV=1` swaps `WlSessionLock` for a `FloatingWindow`. Both must work with zero privileges.
- Theme parity with the author's hyprlock: bg gradient `#0b1526→#12233d→#0a1a2e`, accent `#78d2ff`, text `#ebf5ff`, success `#7dffa8`/`#2ecc71`, font `JetBrainsMono Nerd Font` (installed).
- Builders write files only — no full builds, no `git commit` (orchestrator commits after sanity check). Every non-trivial unit ships a runnable check script under `scripts/`.

### Task 9 (Integration): shell.qml + IPC + wiring

**Files:**
- Create: `shell/shell.qml`, `scripts/test-ipc.sh`
- Modify: `shell/LockContent.qml` (mount FacePlaque in plaqueSlot; forward keyPressed)

**Interfaces:**
- Consumes: every contract above.
- Produces:
  - `shell/shell.qml`:

```qml
import QtQuick
import Quickshell
import Quickshell.Io
import Quickshell.Wayland

ShellRoot {
    id: root
    readonly property bool devMode: Quickshell.env("MUGLOCK_DEV") === "1"

    FaceScanner { id: scanner }

    function beginScan() { plaqueOf().phase = "scanning"; scanner.start() }
    // exact wiring: scanner.succeeded → plaque.phase="success";
    // plaque.successShown → lock.locked=false (or window close in dev);
    // scanner.failed → plaque.phase="failed"; LockContent.keyPressed while
    // failed → beginScan(); LockContent.unlockRequested (PAM) → immediate unlock.

    WlSessionLock {
        id: sessionLock   // NOT `lock` — would collide with IpcHandler's function lock()
        locked: false
        WlSessionLockSurface { LockContent { /* wiring as above */ } }
    }
    // devMode: FloatingWindow { LockContent { … } } instead of the real lock.

    IpcHandler {
        target: "muglock"
        function lock(): void { sessionLock.locked = true; root.beginScan() }
        function wake(): void { if (sessionLock.locked || root.devMode) root.beginScan() }
    }
}
```

  - IPC contract (documented in README, used by hypridle): `qs -c muglock ipc call muglock lock`, `qs -c muglock ipc call muglock wake`.
  - Unlock rule: `lock.locked = false` ONLY from `plaque.successShown` or PAM success. Abort scan on display-off is out of v1 (hypridle sends `wake` on resume anyway; scanner timeout releases the camera).
